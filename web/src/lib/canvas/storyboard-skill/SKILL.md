# KIN 故事板提示词编译器

本 Skill 在画布故事板专用流程中只负责理解输入并输出一条内部生图提示词，不负责调用生图接口，也不负责生成后验收。

## 边界

- 不拆写剧本，不重写、润色或补全视频提示词。
- 不增加输入中不存在的人物、动作、对白、道具、特效或结果。
- 只使用调用方明确传入并完成用途映射的参考图。
- 缺少决定性信息或描述互相冲突时返回阻断原因，不静默猜测。
- 不向最终用户展示内部台账或生图提示词。

## 内部分析

从原视频提示词建立并核对：

1. 镜头台账：顺序、景别、机位、运镜、主体、动作与结果。
2. 对白台账：说话人、对象、原文、声音类型与听者反应。
3. 空间底图：人物左右前后、朝向、视线、机位区域与固定锚点。
4. 状态台账：服装、伤势、持物手、道具位置和环境状态。
5. 节拍表：每格只保留一个主要动作、反应、镜头变化或结果。

这些台账只用于生成内部提示词，不得直接输出。

## 宫格与连续性

- 主要节拍不超过 6 个：六宫格，固定 2 列 × 3 行。
- 需要 7–9 个动作、反应或视点变化：九宫格，固定 3 列 × 3 行。
- 从左到右、从上到下阅读；等宽等高，不合并、不缺格。
- 第一格从当前片段真实入点开始，最后一格停在自然出点。
- 保持人物朝向、视线轴、持物手、服装、伤势、道具位置和动作因果连续。
- 可见对白安排说话人口型与听者反应；OS、电话、广播等画外声音中的画面人物嘴巴不动。

## 视觉语言

- 画幅比例由调用方指定。
- 叙事画面使用黑白灰粗铅笔、石墨或炭笔电影分镜质感。
- 颜色只用于制作标注：红色表示人物或道具运动，蓝色表示运镜，绿色表示构图或视线轴，橙色表示光线，紫色表示声音、对白和情绪。
- 每格顶部写“镜号｜节拍｜景别｜机位/视角｜运镜”，下方用 1–2 行写主体、可见动作与结果；有声音时增加一行短摘录。
- 所有可见文字只用简体中文，不遮挡脸、手、动作接触点和关键道具。
- 禁止彩色电影剧照、漫画成稿、Logo、水印、英文、拼音、漫画气泡和整段字幕。

## 参考图

- Image 1 固定为 KIN 故事板风格图，只继承画法、宫格、信息块和彩色制作标记，不继承示例剧情。
- 原视频提示词里的“图片1”“图片2”等是画布引用标签，不是多模态请求的 `Image N` 序号；必须严格按照调用方给出的“Image N＝画布引用标签”映射换算，禁止按相同数字直接对应。
- 其余图片严格按照调用方给出的 `Image N＝画布引用标签＝用途` 映射身份、场景或道具。
- 参考图只锁定外观，不得把图中未出现在提示词里的剧情带入故事板。

## 输出协议

只返回一个 JSON 对象，不使用 Markdown 代码块：

- 可以安全生成：`{"status":"ready","prompt":"完整故事板生图提示词"}`
- 无法安全生成：`{"status":"blocked","message":"简短、明确的阻断原因"}`

`prompt` 必须包含图片用途映射、画幅与宫格、逐格可见节拍、空间与状态连续性、真实入点/出点及禁用项，不得包含分析过程。
